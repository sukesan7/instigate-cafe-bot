# Instigate Cafe Bot — Development, Testing & UI Conventions

This guide covers contributor environment setup, operational safety tiers, offline tests, CI workflows, and Discord embed/interaction conventions. For PR etiquette and safety rules, see [`CONTRIBUTING.md`](../CONTRIBUTING.md).

## 1. Python Support Matrix, Packaging & Contributor Setup

| Python Version | Metadata (`pyproject.toml`) | Offline CI Matrix | Notes |
| :--- | :--- | :--- | :--- |
| `< 3.11` | Unsupported (`>=3.11,<3.14`) | Not run | Runtime uses Python 3.11+ `datetime.UTC`. |
| `3.11` | Supported | Tested | Matches Ruff `target-version = "py311"`. |
| `3.12` | **Recommended Default** | Tested | Matches `[tool.mypy] python_version = "3.12"` and `Dockerfile`. |
| `3.13` | Supported | Tested | Pulls `audioop-lts>=0.2.2; python_version >= '3.13'`. |
| `3.14+` | Excluded (`<3.14`) | Not run | On rolling distros shipping system Python 3.14, run `uv venv --python 3.12`. |

### Packaging Files
- [`pyproject.toml`](../pyproject.toml) — Single source of truth for runtime dependencies, `[dependency-groups] dev`, Pytest, Coverage (`branch = true`), Ruff, and Mypy settings (`[tool.uv] package = false`).
- [`uv.lock`](../uv.lock) — Locked dependency graph checked with `uv lock --check`.
- [`requirements.lock`](../requirements.lock) & [`requirements.txt`](../requirements.txt) — Autogenerated exports (`make export-requirements`) for standard `pip` installs and `pip-audit`. Never hand-edit them.

### Provisioning a Contributor Environment

```bash
# Recommended with uv (Python 3.12)
uv venv --python 3.12
uv sync --frozen --dev
uv run pre-commit install

# Fallback with standard Python + pip (outside uv)
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/pip install pytest pytest-asyncio pytest-cov aioresponses ruff mypy pre-commit pip-audit

# After changing dependencies in pyproject.toml (requires network):
uv lock && make export-requirements
```

## 2. Operational Safety Tiers, Pre-Commit & CI

Developer targets in [`Makefile`](../Makefile) force offline environment variables (`DISCORD_TOKEN=""`, `ICBOT_ALLOW_GATEWAY="false"`, `LLM_ENABLED="false"`, `MARKET_WATCH_ENABLED="false"`, `BTC_WATCH_ENABLED="false"`, `JOBS_POLL_SECONDS="0"`):

| Safety Tier | Commands | Side-Effect Boundary |
| :--- | :--- | :--- |
| **Tier 1: Static** | `uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy .`, `uv run python tools/check_syntax.py`, `uv run python tools/check_docs.py` | Zero runtime execution, zero network I/O, zero DB writes. |
| **Tier 2: Offline Runtime** | `uv run pytest`, `uv run python tools/smoke_offline.py`, `uv run python tools/smoke_staging.py`, `uv run python tools/scan_secrets.py --enforce-clean`, `uv run python tools/check_command_docs.py` | Synthetic temp SQLite DBs, fake Discord interactions, mocked HTTP routers, and blocked outbound IPv4/IPv6 sockets. |
| **Tier 3: Package Metadata** | `uv lock --check`, `uv run pip-audit --desc auto` (`make audit`) | Queries PyPI/OSV advisory metadata only. Never touches Discord or bot APIs. |
| **Tier 4: Live / Operator-Only** | `uv run python main.py --allow-gateway`, `uv run python scripts/admin/purge_global_commands.py --execute ...` | Never executed in CI, pre-commit, or tests. `purge_global_commands.py` defaults to `--dry-run`. |

### Offline Pre-Commit & GitHub Actions Workflows
- **[`.pre-commit-config.yaml`](../.pre-commit-config.yaml):** Runs `repo: local` hooks (`block-forbidden-files`, `tools/scan_secrets.py --enforce-clean`, `block-private-key-blocks`, `tools/check_syntax.py`, Ruff lint/format) offline.
- **[`.github/workflows/ci.yml`](../.github/workflows/ci.yml) (Quality & Security Gate):** Uses `permissions: contents: read` with zero live secrets. Separates offline matrix checks (`quality` across Python `3.11`, `3.12`, and `3.13`: lockfile check, secret scan, pre-commit, Ruff, Mypy, offline AST/staging smokes, doc/command parity, usability benchmark, and `pytest --cov=icbot`) from the networked `dependency-audit` job (`pip-audit --desc auto`).
- **[`.github/workflows/live-smoke.yml`](../.github/workflows/live-smoke.yml):** Manual `workflow_dispatch`-only workflow (no schedule, never runs on PRs) that exits `DISABLED` unless both `confirm_live_network: true` and repository secret `OPT_IN_LIVE_SMOKE=true` are present.
- **[`.github/dependabot.yml`](../.github/dependabot.yml):** Weekly `pip` and `github-actions` update checks.

## 3. Offline Test Suite & Verification Scripts

`pyproject.toml` sets `addopts = "--strict-markers -m 'not live_smoke'"`, excluding opt-in live probes by default.

### Pytest Markers & Test Isolation ([`tests/conftest.py`](../tests/conftest.py))
| Marker | Scope | External I/O |
| :--- | :--- | :--- |
| `unit` | Config, math/PRNG engines, permissions, embeds, theme luminance, export/erasure, SSRF, doc/command checks | None |
| `storage` | SQLite WAL persistence, concurrency locks, multi-guild ledgers, Schema v1–v7 migrations | Temp `tmp_path` SQLite |
| `discord_mock` | Slash commands, `BasePaginationView` / `BaseConfirmView` guards, RBAC via `FakeInteraction` / `FakeClient` | Mocked Discord |
| `provider_contract` | Parsers, ATS pipeline, circuit breakers, and HTTP error-family matrix | Monkeypatched `aiohttp` + [`tests/fixtures/`](../tests/fixtures/) |
| `live_smoke` | Opt-in public endpoint smoke (`go_transit`, `ttc_mastodon`, `sports_odds`, `crypto_fng`; excluded by default) | Requires `OPT_IN_LIVE_SMOKE=true` + `--enable-live-network` |

Two `autouse=True` fixtures protect every automated test run:
1. **`_disable_outbound_network`:** Blocks IPv4/IPv6 `socket.connect` / `connect_ex`, `socket.create_connection`, external `socket.getaddrinfo`, `urllib.request.urlopen`, `http.client`, and unmocked `aiohttp.ClientSession._request`, raising [`OfflineNetworkDisabledError`](../tests/helpers.py).
2. **`_isolate_environment`:** Clears provider keys and pollers (`ICBOT_ALLOW_GATEWAY=false`), stubs `dotenv.load_dotenv` so private `.env` files are never read, and resets cached sessions/locks.

### Contributor Verification Commands
```bash
# Single-command offline verification suite (interpreter, lockfiles, secrets, smokes, docs, ruff, mypy, pytest)
uv run python tools/verify_offline.py
# Fast static/doc pass while iterating:
uv run python tools/verify_offline.py --fast

# Individual test & verification commands
uv run pytest
uv run pytest --collect-only
uv run pytest -m unit
uv run pytest --cov=icbot --cov-report=term-missing
uv run python tools/smoke_offline.py
uv run python tools/smoke_staging.py
uv run python tools/check_docs.py
uv run python tools/check_command_docs.py
uv run python tools/scan_secrets.py --enforce-clean
```

`tools/run_live_smoke.py` enforces `DISCORD_TOKEN=""`, `GEMINI_API_KEY=""`, `ICBOT_ALLOW_GATEWAY=false`, `DB_PATH=:memory:`, byte/timeout caps, and fails closed (`DISABLED` / `SKIPPED_UNCONFIGURED`) if credentials are absent or zero checks run; opt-in live probes live in [`scripts/manual/`](../scripts/manual/README.md) (`probe_*.py`) and maintenance helpers in [`scripts/admin/`](../scripts/admin/README.md). Internal synthetic acceptance/benchmark scripts (`run_staging_acceptance.py`, `verify_beta_readiness.py`, `run_usability_audit.py`, `benchmark_db.py`, `benchmark_profile.py`) are exercised offline by the test suite.

### Implemented Claim Boundaries (Tests vs. Live Deployment)
- **Economy & casino:** Pure Python PRNG engines (`blackjack_engine.py`, `roulette_engine.py`, `slots_engine.py`), not cryptographic commit-reveal; ledger mutations use `BEGIN IMMEDIATE` SQLite transactions.
- **SQLite storage:** Data sits in plaintext local SQLite (`DB_PATH`); disk encryption is the host operator's responsibility.
- **UI contrast check:** [`icbot/theme.py`](../icbot/theme.py) checks a relative luminance range heuristic ($0.03 \le L \le 0.95$) using the WCAG luminance formula—not full text-to-background WCAG contrast certification.
- **Offline tests vs. live hosting:** Automated tests mock Discord interactions, network HTTP calls, and temporary SQLite databases; real Docker builds on a host daemon, Railway volume cutover, and live Discord slash-command sync require manual execution.

## 4. Maintainer Engineering Invariants & Secret Remediation

1. **Migrations:** Keep SQLite schema changes forward-compatible and verify hot backups (`tools/backup_db.py`).
2. **Dynamic registration:** Before deleting a module, verify `/ic` commands in [`icbot/registry.py`](../icbot/registry.py), task specs in [`icbot/scheduler.py`](../icbot/scheduler.py), and CLI scripts under `tools/`.
3. **If a forbidden file is accidentally staged:**
   ```bash
   git rm --cached data/dev.db data/dev.db-wal .env.local tools/lore.private.json
   uv run python tools/scan_secrets.py --enforce-clean
   ```
   If a real secret was committed, revoke it immediately per [`SECURITY.md`](../SECURITY.md) and clean history per [Deployment Security Remediation](deployment.md#91-pre-publication-security-and-history-remediation).

## 5. Discord UI and Interaction Conventions

**Primary Modules:** [`icbot/embeds.py`](../icbot/embeds.py), [`icbot/theme.py`](../icbot/theme.py), [`icbot/ui.py`](../icbot/ui.py)

### 5.1 Theme Presets & Semantic Status Colors
The default `instigate_cafe` purple (`0xA64DFF`) is resolved per server via `resolve_guild_settings(bot, guild_id)`:

| Preset (`theme_preset`) | Display Name | Accent (`embed_accent_color`) | Footer Brand (`embed_footer_text`) |
| :--- | :--- | :--- | :--- |
| `instigate_cafe` (default) | `InstigateAI` | `0xA64DFF` (Purple) | `Instigate Cafe` |
| `campus_generic` | `Campus Assistant` | `0x2563EB` (Royal Blue) | `Campus Utility` |
| `student_clean` | `Student Bot` | `0x0284C7` (Sky Blue) | `Student Portal` |
| `toronto_tmu` | `TMU Campus Bot` | `0x004C97` (TMU Blue) | `TMU Student Hub` |
| `emerald_academic` | `Academic Bot` | `0x059669` (Emerald Green) | `Academic Commons` |

Semantic statuses (`"normal"` / `"info"` → accent, `"success"` → `0x2ECC71`, `"warning"` → `0xF39C12`, `"error"` → `0xE74C3C`, `"disabled"` → `0x64748B`) are checked against the relative luminance heuristic $0.03 \le L \le 0.95$.

### 5.2 Embed Bounds, Markdown Safety & Hyperlinks
- **Character limits:** `_base_embed` and `_add_fields` enforce Discord limits (title ≤ 256, description ≤ 4096, field name ≤ 256, field value ≤ 1024, ≤ 25 fields, ≤ 6000 total characters) with surrogate-safe Unicode truncation (`_normalize_unicode_safe`).
- **Formatting & mentions:** Bot-authored text uses `sanitize_text` (inserts `\u200b` into `@everyone`, `@here`, `<@...>`); untrusted external/user text uses `sanitize_untrusted_text` (`discord.utils.escape_markdown` + sanitization); hyperlinks pass `safe_http_url` (`http(s)://` only).
- **Allowed mentions:** `CampusBot.__init__` sets `allowed_mentions=discord.AllowedMentions.none()` client-wide. Only configured job-alert role subscriptions use `alert_role_allowed_mentions(role_id)`, permitting exclusively that single role.

### 5.3 Interaction-Audience Matrix & `SHARED_INTERACTION_EXCEPTIONS`
[`icbot/ui.py`](../icbot/ui.py) separates pagination math (`compute_page_slice`) from Discord UI state (`BasePaginationView`), enforces single ephemeral denials (`send_ephemeral_denial` with `_last_checked_interaction_id` deduplication), re-verifies module enablement and admin permissions mid-session (`resolve_live_view_settings`), and handles Discord `403`/`404`/`429` cleanly:

| View Class | Audience Policy | Timeout | Delivery Mode |
| :--- | :--- | :---: | :--- |
| `NotesPaginationView` | **Guild-Shared** (`owner_id=0` default; invoker-only if `owner_id > 0`) | `180s` | Public |
| `ExamPaginationView` | **Invoker-Only** (`owner_id` + `guild_id`) | `180s` | Public or Ephemeral (if private exams) |
| `ExamClearConfirmView` | **Initiating Admin Only** | `60s` | Ephemeral |
| `JobPaginationView` | **Invoker-Only** (`owner_id` + `guild_id`) | `180s` | Public |
| `ResumeReviewPaginationView` / `ResumeConfirmView` | **Invoker-Only** | `180s` / `120s` | Ephemeral |
| `HelpPaginationView` / `GettingStartedView` | **Invoker-Only** when `author_id` set (`SHARED_INTERACTION_EXCEPTIONS` if `author_id=None`) | `180s` | Public |
| `LeaderboardView` | **Invoker-Only** | `180s` | Public |
| `GuildSetupView` / `AdminMarketConfirmView` | **Admin-Only** (`guild_id` + live `can_manage_guild` / `is_admin_or_allowed`) | `300s` / `60s` | Ephemeral |
| `BlackjackView` / `BlackjackTerminalView` | **Player-Locked** (`(guild_id, user_id)` + `asyncio.Lock`) | `120s` / `60s` | Public |

Deliberate shared navigation (`SHARED_INTERACTION_EXCEPTIONS`) is limited to `NotesPaginationView` (`owner_id == 0`) and `HelpPaginationView` / `GettingStartedView` (`author_id=None`), where every page contains static/public guild content.
