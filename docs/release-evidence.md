## 1. Corrections Applied During Independent Security Review

The following overstated or imprecise claims were identified and corrected across code and documentation:

| Previous Claim | Location(s) | Technical Reality & Trust Boundary | Corrected Claim |
| :--- | :--- | :--- | :--- |
| `"Local Encrypted Storage"` in `/ic job_preferences` embed footer | `icbot/features/jobs.py` | SQLite (`icbot/db.py`) stores `user_job_preferences` in **plaintext local SQLite** (`DB_PATH`). Application-level encryption is not implemented; encryption at rest depends on the host operator's filesystem/volume encryption. | `"Instigate Cafe Bot • Local SQLite Storage (Plaintext on Host Disk)"` |
| Ambiguous guild vs. global scope for `user_job_preferences` | `icbot/features/jobs.py`, `docs/architecture/job-alerts-and-ats-ingestion.md` | `user_job_preferences` is keyed by `user_id INTEGER PRIMARY KEY` (`"scope": "global_user"`). It is an intentional portable user preference across servers sharing one bot instance, guarded on guild deletion by `UserStore.delete_user_data`. | Explicitly disclosed in `/ic job_preferences` embed and docs as portable user-ID-scoped (`global_user`) preferences stored in local SQLite. |
| `"WCAG AA compliant"` / `"WCAG Compliance"` for theme accent colors | `icbot/theme.py`, `docs/architecture/branding-theming-and-localization.md` | `calculate_luminance()` uses the W3C WCAG 2.1 relative luminance formula ($L \in [0, 1]$), and `is_accessible_accent()` checks $0.03 \le L \le 0.95$ for Discord's embed sidebar stripe. It does **not** measure or certify WCAG 2.1 AA ($4.5:1$ / $3:1$) text-to-background contrast ratios. | Described accurately as a **relative luminance range heuristic ($0.03 \le L \le 0.95$)** using the WCAG 2.1 relative luminance formula. |
| `"provably fair math engines"` for `/ic casino` games | `README.md` | `icbot/games/blackjack_engine.py`, `roulette_engine.py`, and `slots_engine.py` use standard Python `random.Random` pseudo-random number generators (PRNG) with unit-tested payout tables. There is no cryptographic commit-reveal seed protocol. | `"unit-tested PRNG game engines with deterministic payout tables"` |
| Broad `"never-listening"` / `"never collected"` chat statements | `README.md`, `icbot/features/info.py`, `docs/privacy.md`, `docs/alpha-beta-readiness.md` | The bot never writes chat messages to local disk or SQLite, and **no automatic channel-history collection occurs by default** (`LLM_CHANNEL_HISTORY_ENABLED=false`). However, if an operator explicitly sets `LLM_ENABLED=true` and `LLM_CHANNEL_HISTORY_ENABLED=true`, an `@mention` reads up to `max(10, min(100, LLM_MAX_MESSAGES * 2))` recent channel messages in memory for that single Gemini API request. | Distinguishes **no local chat persistence and no automatic channel-history collection by default** from opt-in `@mention` context when `LLM_CHANNEL_HISTORY_ENABLED=true`. |
| Unqualified `"zero retention"` on resume uploads | `icbot/features/resume.py`, `icbot/features/info.py`, `docs/privacy.md`, `docs/launch-assets.md` | The bot process holds attachment bytes only in transient RAM and never writes them to local disk or SQLite. However, slash-command attachments and ephemeral reply payloads transit **Discord's CDN/platform** under Discord's Privacy Policy, and confirmed AI reviews transmit bytes to **Google Gemini** under the operator's Google API terms. | Distinguishes **zero local disk/SQLite storage by this application** from Discord platform retention and Google Gemini API retention policies. |
| `"RELEASE CANDIDATE CERTIFIED (GO FOR BETA)"` / `"GDPR-compliant"` | `tools/verify_beta_readiness.py`, `docs/alpha-beta-readiness.md`, `docs/staging-acceptance-and-fault-injection.md`, `docs/launch-assets.md` | All 8 release gates and 27 staging scenarios execute against **offline mocked Discord interactions and temporary SQLite databases**. Live Discord gateway sync, real upstream credentials, and human cohort trials have not been executed. Technical RTBF helpers are not a legal GDPR certification. | Labeled as **offline simulated release gates (`READY FOR OWNER-RUN STAGING`)** and **operator-executed Right-to-be-Forgotten data export and deletion/anonymization utilities**. |
